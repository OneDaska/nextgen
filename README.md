# NextGen Dashboard

Production domain: nextgen.laineworkflow.online

## Hostinger deployment settings

- Repository: OneDaska/nextgen
- Branch: main
- Application root: repository root
- Framework: Next.js
- Node.js: 24 where available (22 is also supported by Next.js)
- Install: pnpm install --frozen-lockfile
- Build: pnpm build
- Start: pnpm start

Database changes are managed separately. Do not rerun migrations during deployment.
Evidence supports PNG, PDF, DOC, DOCX and XLSX up to 1,000,000 bytes per file, plus HTTP(S) document links. Attachments are private to the assigned function and administrator, stored in Supabase with row-level access controls. Uploads use the signed-in user token; no service key is required.

Configure Supabase authentication to allow https://nextgen.laineworkflow.online/nextgen.html for invitation and recovery redirects, and set the production site URL once the deployment is verified.

Real-account sign-in and invitation/reset delivery still require verification. All nine functions have five official KPIs from the supplied cards; agreed targets and technology milestone scoring still require administrator configuration. Temporary-password onboarding is available through a one-time authorized server operation. The database requires an actual password change before workspace, report or evidence access is restored; the sign-in screen presents password setup first.
